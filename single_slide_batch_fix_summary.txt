Single-Slide Batch Mode Fix Summary
====================================
Date: November 8, 2025

Problem Identified:
------------------
When batch processing created a batch with only 1 slide (e.g., 9 slides grouped 
into batches of 8 results in batch_1=8 slides and batch_2=1 slide), the single-
slide batch would fail because:

1. The condition checked `if slide_paths and len(slide_paths) > 1`
2. This meant single-slide batches fell into "single slide mode"
3. OUTPUT_H5_PATH and OUTPUT_PT_PATH were set to None (string "None")
4. The task script tried to execute "None" as a command, causing failure

Root Cause:
-----------
In both scripts/slurm/submit_slurm_jobs.py and scripts/condor/submit_condor_jobs.py:

Line ~150:
  if slide_paths and len(slide_paths) > 1:  # Only multi-slide batches!
      # Batch mode...
  else:
      # Single slide mode (set None values)

Fix Applied:
-----------
Changed the condition from `len(slide_paths) > 1` to `len(slide_paths) >= 1`
This ensures that even single-slide batches use batch mode environment variables.

Before:
  if slide_paths and len(slide_paths) > 1:
      # Batch processing mode
      env_vars["SLIDE_PATHS"] = ",".join(slide_paths)
      env_vars["SLIDE_IDS"] = ",".join(slide_ids)
      env_vars["OUTPUT_DIR"] = output_dir_for_batch
      env_vars["SLIDE_BATCH_SIZE"] = str(slide_batch_size)
  else:
      # Single slide - sets OUTPUT_H5_PATH=None
      env_vars["SLIDE_PATH"] = slide_path
      env_vars["OUTPUT_H5_PATH"] = output_h5_path  # None!
      env_vars["OUTPUT_PT_PATH"] = output_pt_path  # None!

After:
  if slide_paths and len(slide_paths) >= 1:  # Include single-slide batches
      # Batch processing mode (including single-slide batches)
      env_vars["SLIDE_PATHS"] = ",".join(slide_paths)
      env_vars["SLIDE_IDS"] = ",".join(slide_ids)
      env_vars["OUTPUT_DIR"] = output_dir_for_batch
      env_vars["SLIDE_BATCH_SIZE"] = str(slide_batch_size)
  else:
      # True single slide mode (non-batch, backward compatible)
      env_vars["SLIDE_PATH"] = slide_path
      env_vars["OUTPUT_H5_PATH"] = output_h5_path
      env_vars["OUTPUT_PT_PATH"] = output_pt_path
