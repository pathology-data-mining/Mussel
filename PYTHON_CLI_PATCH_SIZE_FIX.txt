Python CLI Default Patch Size Fix - COMPLETE
============================================
Date: November 9, 2025

Problem:
--------
The Python CLI command didn't apply model-specific patch size defaults.
Hydra doesn't call __post_init__() on structured configs automatically.

When running:
  tessellate_extract_features \
    prefilter_model_type=CTRANSPATH \
    seg_config=biopsy

The system used patch_size=256 (default) causing:
  AssertionError: Input image size (256*256) doesn't match model (224*224)

Root Cause:
-----------
Hydra's structured config system doesn't invoke dataclass __post_init__() methods.
The initialization logic in __post_init__() was never being executed.

Solution:
---------
Moved the model-specific patch size initialization from __post_init__() 
to the main() function where it runs for every invocation:

def main(cfg: TessellateExtractFeaturesConfig):
    # Apply model-specific defaults if not explicitly set
    if cfg.seg_config.patch_size == SegConfig.DEFAULT_PATCH_SIZE:
        try:
            recommended_patch_size = get_default_patch_size(cfg.prefilter_model_type)
            if recommended_patch_size != SegConfig.DEFAULT_PATCH_SIZE:
                logger.info(
                    f"Setting seg_config.patch_size={recommended_patch_size} based on "
                    f"model_type={cfg.prefilter_model_type.name}"
                )
                cfg.seg_config.patch_size = recommended_patch_size
        except (ValueError, AttributeError):
            pass
