Final Patch Size Default Fix Summary
=====================================
Date: November 9, 2025

Problem:
--------
When using CTRANSPATH (or other models) without explicitly setting patch_size,
the system used the default 256, causing assertion errors.

Solution:
---------
Added model-specific default patch size selection in Python CLI only.
Removed redundant bash script logic to avoid code duplication.

Single Source of Truth:
-----------------------
mussel/cli/tessellate_extract_features.py - main() function

def main(cfg: TessellateExtractFeaturesConfig):
    # Apply model-specific defaults if not explicitly set
    if cfg.seg_config.patch_size == SegConfig.DEFAULT_PATCH_SIZE:
        try:
            recommended_patch_size = get_default_patch_size(cfg.prefilter_model_type)
            if recommended_patch_size != SegConfig.DEFAULT_PATCH_SIZE:
                logger.info(
                    f"Setting seg_config.patch_size={recommended_patch_size} based on "
                    f"model_type={cfg.prefilter_model_type.name}"
                )
                cfg.seg_config.patch_size = recommended_patch_size
        except (ValueError, AttributeError):
            pass

Model-to-Patch-Size Mapping:
----------------------------
Defined in: mussel/models/model_factory.py - MODEL_PATCH_SIZES dict

224px: CTRANSPATH, VIRCHOW, VIRCHOW2, OPTIMUS, CLIP, GOOGLEPATH
512px: CONCH1_5, TITAN_SLIDE
256px: RESNET50, GIGAPATH, UNI, UNI2, GIGAPATH_SLIDE
