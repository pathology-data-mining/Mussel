Azure Batch YAML Parameters Fix
================================
Date: November 9, 2025

Problem:
--------
Some Azure-specific parameters from the YAML config file were not being
applied to the Azure Batch script, specifically:
- node_agent_sku_id
- output_dir_azfiles

Root Cause:
-----------
The script was loading config_defaults correctly via load_config_defaults(),
but two parameters were missing from the parameter application logic:

1. node_agent_sku_id - Has a default value but wasn't checked against config
2. output_dir_azfiles - Not handled at all in the config application section

Solution:
---------
Added missing parameter handling in submit_batch_jobs.py:

# Node agent SKU ID
if args.node_agent_sku_id == "batch.node.ubuntu 20.04" and 'node_agent_sku_id' in config_defaults:
    args.node_agent_sku_id = config_defaults['node_agent_sku_id']

# Output directory for Azure Files
if 'output_dir_azfiles' in config_defaults:
    if not hasattr(args, 'output_dir_azfiles') or args.output_dir_azfiles is None:
        args.output_dir_azfiles = config_defaults['output_dir_azfiles']
