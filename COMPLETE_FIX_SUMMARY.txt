CACHE ISOLATION STRATEGY
-------------------------

Problem: Multiple concurrent tasks writing to same cache ‚Üí corruption

Solution: Task-specific directories using AZ_BATCH_TASK_ID

Why PyTorch cache is isolated:
  - CUDA kernel compilation writes temp files
  - Race conditions during model init
  - Not safe for concurrent writes

Why HuggingFace cache is shared:
  - Downloaded once, read by all
  - Built-in download locking
  - Read-only after download
