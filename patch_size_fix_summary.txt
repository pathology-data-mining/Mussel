Patch Size Mismatch Fix Summary
================================
Date: November 8, 2025

Problem Identified:
------------------
When using seg_config groups (e.g., seg_config=biopsy), individual seg_config 
parameters like patch_size and step_size were being ignored. The script only 
passed individual parameters if NO group was specified.

Root Cause:
-----------
In scripts/common/run_tessellate_extract_features.sh, there were three locations 
where individual seg_config parameters were wrapped in:
  if [ -z "$SEG_CONFIG_GROUP" ]; then

This prevented parameter overrides when using a config group.

Fix Applied:
-----------
Removed the conditional check that prevented individual parameters from being 
passed when a seg_config group was specified. Now individual parameters always 
override group defaults, following the principle of "explicit overrides implicit".

Changed 3 locations in run_tessellate_extract_features.sh:
1. Line ~359: Main batch processing command
2. Line ~520: Filter command
3. Line ~734: Single slide command

Before:
  if [ -n "$SEG_CONFIG_GROUP" ]; then
      CMD_ARGS+=("seg_config=${SEG_CONFIG_GROUP}")
  fi
  if [ -z "$SEG_CONFIG_GROUP" ]; then  # Only if no group!
      if [ -n "$PATCH_SIZE" ]; then
          CMD_ARGS+=("seg_config.patch_size=${PATCH_SIZE}")
      fi
  fi

After:
  if [ -n "$SEG_CONFIG_GROUP" ]; then
      CMD_ARGS+=("seg_config=${SEG_CONFIG_GROUP}")
  fi
  # Always add individual parameters (they override group defaults)
  if [ -n "$PATCH_SIZE" ]; then
      CMD_ARGS+=("seg_config.patch_size=${PATCH_SIZE}")
  fi

string "None" instead of actual path. This is a separate issue in the 
batch generation code for edge cases where batch size = 1.

Impact: Not critical since single slides should use standard array mode,
not batch mode. Batch mode is designed for multiple slides.
